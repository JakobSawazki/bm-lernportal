# Uebergabe und Wiedereinstieg

## Projektziel

Die fruehere BM-Homepage soll wiederhergestellt, aktualisiert, geprueft und
spaeter online gestellt werden.

## Aktueller Stand

- Release `1.0.1` ist vollständig entwickelt und getestet.
- Der produktive Webcode liegt in `website/`.
- GitHub-Remote: `JakobSawazki/bm-lernportal`
- Veröffentlichung: GitHub Pages über GitHub Actions
- Lernstand wird ausschließlich lokal im Browser gespeichert.

## Wichtigste naechste Schritte

1. Rückmeldungen der Lernenden sammeln.
2. Weitere Inhalte fachlich prüfen und in `website/content.js` ergänzen.
3. JavaScript- und Browsertests durchführen.
4. Versionsnummer und Changelog aktualisieren.
5. Nach `main` pushen und Pages-Deployment prüfen.

## Arbeitsregeln

- Keine Zugangsdaten in Dateien oder Git-Commits speichern.
- Keine privaten Prüfungen oder personenbezogenen Inhalte veröffentlichen.
- Neue Quellen in `QUELLEN.md` protokollieren.
- Wesentliche Entscheidungen in `ENTSCHEIDUNGEN.md` festhalten.
- Abgeschlossene Änderungen in `CHANGELOG.md` dokumentieren.

## Abschlusskriterien

Das Projekt ist erst dann als vollstaendig uebergeben anzusehen, wenn:

- die Website lokal reproduzierbar laeuft,
- der Quellcode vollstaendig versioniert ist,
- das GitHub-Repository dokumentiert ist,
- Tests und Freigaben nachvollziehbar sind,
- die produktive URL bekannt ist und
- der Veröffentlichungsweg wiederholbar beschrieben ist.
